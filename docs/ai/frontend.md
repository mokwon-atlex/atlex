# 프론트엔드 AI 작업 지침

이 문서는 `frontend/**`를 변경할 때 `docs/ai/README.md`와 함께 적용합니다. 코딩 컨벤션은 `CONTRIBUTING.md`의 프론트엔드 항목을 원본으로 사용합니다.

## 작업 전 확인

- 변경할 컴포넌트, Hook, API 모듈과 인접 테스트의 기존 패턴을 먼저 확인합니다.
- 프론트엔드만의 기능으로 단정하지 않고 백엔드 API와 데이터 계약 영향을 확인합니다.
- `.next`, `coverage`, `storybook-static`과 의존성 폴더 같은 생성물을 직접 수정하지 않습니다.
- 실제 환경 변수 파일을 열지 않고 `frontend/.env.example`을 기준으로 공개 설정 구조만 확인합니다.

## 구현과 검증

- 화면 변경이 있으면 주요 상태, 반응형 레이아웃, 키보드 조작과 접근성을 확인합니다.
- 화면 변화가 없는 기능 변경도 관련 테스트와 빌드를 실행합니다.
- API 또는 데이터 구조를 변경하면 백엔드 DTO, Swagger, 소비 코드와 테스트를 함께 확인합니다.
- 내부 구현을 과도하게 모킹하지 않고 사용자가 관찰할 수 있는 동작을 검증합니다.
- UI를 직접 확인할 수 없으면 확인하지 않은 항목과 대체 검증 결과를 보고합니다.

변경 영역 검증은 저장소 루트에서 실행합니다.

```bash
npm run check:frontend
```

필요한 검사를 개별 실행할 때는 `frontend` 디렉터리의 기존 npm 스크립트를 사용합니다. PR 생성 전에는 루트에서 `npm run check` 전체 검사를 실행합니다.
